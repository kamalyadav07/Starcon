# Starcon React

React + Vite app for Starcon Infra.

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Structure

```text
starcon-react/
  public/          Static files served by Vite
  src/             React source files
  index.html       App HTML entry
  vite.config.js   Vite and Tailwind setup
```
